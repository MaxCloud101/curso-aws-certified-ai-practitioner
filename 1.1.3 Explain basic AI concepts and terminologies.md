# Tipos de aprendizaje

En Inteligencia Artificial (IA), existen diferentes tipos de aprendizaje que permiten a una máquina aprender a partir de datos, reconocer patrones y realizar predicciones o tomar decisiones.

Los 3 tipos principales de aprendizaje que conviene conocer son: aprendizaje supervisado, no supervisado y por refuerzo.

## 1. Aprendizaje supervisado (Supervised Learning)

Es un tipo de aprendizaje en el que la IA aprende utilizando datos que ya tienen una respuesta correcta o una etiqueta.

Es como cuando un profesor le muestra a un niño fotografías de perros y gatos, indicándole cuál es cuál, hasta que el niño aprende a distinguirlos.


Ejemplo: detectar correos no deseados

| Correo | Etiqueta |
|---|---|
| ¡Ganaste un premio! Haz clic aquí | Spam |
| Tu recibo de electricidad | No spam |
| Gana dinero rápidamente | Spam |
| Confirmación de tu compra | No spam |

La IA estudia los ejemplos y aprende a clasificar los correos nuevos.

Otros ejemplos:
- Predecir el precio de una vivienda según sus características.
- Estimar cuánto gastarás el próximo mes.
- Identificar si una fotografía contiene un perro o un gato.
- Predecir si un cliente podría dejar de utilizar un servicio.

## 2. Aprendizaje no supervisado (Unsupervised Learning)

Es un tipo de aprendizaje en el que la IA recibe datos sin etiquetas o respuestas previamente definidas y busca patrones, relaciones o grupos por sí misma.

Es como colocar una caja llena de juguetes y pedirle a un niño que los organice según sus similitudes, sin decirle cómo hacerlo.

Ejemplo: una tienda que estudia a sus clientes

La tienda analiza los hábitos de compra y descubre grupos como estos:

| Grupo descubierto | Comportamiento |
|---|---|
| Grupo A | Compra frutas y verduras frecuentemente |
| Grupo B | Compra productos de limpieza |
| Grupo C | Compra golosinas y bebidas |


Otros ejemplos:
- Agrupar canciones según su estilo o características.
- Encontrar clientes con hábitos de compra similares.
- Detectar patrones inusuales en transacciones.
- Organizar noticias según sus temas.

## 3. Aprendizaje por refuerzo (Reinforcement Learning)

Es un tipo de aprendizaje en el que un agente aprende a tomar decisiones mediante la interacción con un entorno, recibiendo recompensas o penalizaciones según sus acciones.

Se parece a enseñarle a un perro a realizar un truco: cuando realiza la acción deseada, recibe una recompensa y aumenta la probabilidad de repetirla.

Ejemplo: aprender a jugar un videojuego

Imagina una IA que aprende a jugar un juego de carreras:

1. Intenta acelerar en una curva.
2. Si toma la curva correctamente, obtiene puntos.
3. Si choca, recibe una penalización.
4. Después de muchos intentos, aprende estrategias para conseguir una puntuación mayor.

Otros ejemplos:
- Entrenar una IA para jugar ajedrez.
- Optimizar los movimientos de un robot.
- Aprender a controlar un sistema de climatización.
- Desarrollar estrategias para gestionar recursos en una simulación.

# Entrenamiento e inferencia

## 1. Entrenamiento (Training)

El entrenamiento es el proceso mediante el cual un modelo de IA aprende patrones a partir de datos para realizar una tarea.

Es parecido a estudiar para un examen: practicas con ejemplos, identificas patrones y mejoras tus respuestas.

Otros ejemplos:

- Entrenar un modelo para predecir el precio de las viviendas.
- Entrenar un modelo de lenguaje con grandes cantidades de texto.
- Entrenar un sistema para detectar transacciones fraudulentas.

Idea clave: durante el entrenamiento, el modelo aprende y ajusta sus parámetros.

## 2. Inferencia (Inference)

La inferencia es el proceso en el que un modelo ya entrenado utiliza lo que aprendió para generar una predicción, clasificación o respuesta ante nuevos datos.
Siguiendo el ejemplo anterior, una vez entrenada la IA para reconocer perros, puedes mostrarle una fotografía nueva.

1. Le proporcionas una imagen.

2. El modelo procesa la imagen.

3. Devuelve una predicción, por ejemplo: «Perro, 96 % de confianza».
Ese 96 % es un ejemplo ilustrativo, no una medición real.

Otros ejemplos:

- Cuando ChatGPT responde a una pregunta.
- Cuando una aplicación detecta si un correo es spam.
- Cuando un sistema estima el precio de una vivienda.
- Cuando una cámara identifica un objeto en tiempo real.


Una analogía sencilla: entrenar es estudiar; inferir es responder el examen utilizando lo aprendido.
