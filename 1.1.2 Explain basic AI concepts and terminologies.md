## Datos estructurados y datos no estructurados

### Datos estructurados

Son datos que siguen un formato definido y una organización clara, de modo que un sistema puede identificar fácilmente qué significa cada campo.

Ejemplo cotidiano: un contacto del celular

- Nombre: Ana
- Teléfono: 999 123 456
- Correo: ana@example.com
 
El sistema sabe qué valor corresponde al nombre, al teléfono y al correo.

Otros ejemplos comunes
- Un pedido de comida con productos, cantidades y precios.
- Una cuenta bancaria con fecha, importe y tipo de operación.
- Una reserva de hotel con huésped, habitación y fechas.
- Una ficha de estudiante con código y calificaciones.

### Datos no estructurados

Son datos que no tienen una estructura tabular fija o un esquema uniforme que permita organizarlos directamente en campos predefinidos. Su contenido necesita interpretarse o procesarse para extraer información.

- Ejemplo 1: una fotografía familiar: La foto contiene personas, objetos, colores y un entorno. No viene necesariamente organizada en columnas que indiquen quién aparece y qué está haciendo.

- Ejemplo 2: un audio de WhatsApp: El audio contiene voz, sonidos y silencios. Para saber qué dijo una persona, puedes necesitar convertirlo en texto mediante reconocimiento de voz.

- Ejemplo 3: un video: Un video contiene secuencias de imágenes y, a menudo, audio. Una IA puede analizarlo para identificar personas, acciones o conversaciones.

## Datos etiquetados y sin etiquetar

En Machine Learning, los datos pueden estar etiquetados (labeled data) o sin etiquetar (unlabeled data). La diferencia principal es si cada dato incluye una respuesta o categoría conocida que el modelo pueda utilizar durante el entrenamiento.

### 1. Datos etiquetados (Labeled Data)

Son datos que incluyen información de entrada y una etiqueta que indica qué representa ese dato.

| Dato de entrada                              | Etiqueta             |
| -------------------------------------------- | -------------------- |
| Correo electrónico                           | Spam                 |
| Fotografía de un perro                       | Perro                |
| Transacción bancaria                         | Fraude / No fraude   |
| Precio de una vivienda y sus características | Precio real de venta |
| Texto de una opinión                         | Positiva / Negativa  |

### ¿Cómo aprende el modelo?

En el aprendizaje supervisado (supervised learning), el modelo recibe ejemplos con sus etiquetas y aprende a predecirlas para datos nuevos.

Por ejemplo, si entrenamos un modelo con 10 000 imágenes etiquetadas como gato o perro, podrá aprender patrones visuales que le ayuden a clasificar nuevas imágenes.

### 2. Datos sin etiquetar (Unlabeled Data)

Son datos que contienen información, pero no incluyen una etiqueta que indique la respuesta correcta.

Otros ejemplos:

| Dato                                         |
| --------------------------------------------------- |
| Miles de documentos de texto sin categorías.        |
| Registros de actividad de usuarios sin clasificar.  |
| Fotografías que no indican qué objetos aparecen.    |
| Datos de clientes sin grupos previamente asignados. |

### ¿Cómo aprende el modelo?

Estos datos pueden utilizarse en aprendizaje no supervisado (unsupervised learning) para descubrir estructuras, grupos o patrones.

Por ejemplo, un algoritmo podría agrupar clientes según sus hábitos de compra sin que nadie le haya proporcionado previamente las categorías «cliente frecuente» o «cliente ocasional».

También se pueden utilizar en aprendizaje autosupervisado (self-supervised learning), donde el propio contenido permite construir una tarea de entrenamiento.

### Diferencias principales

| Característica | Etiquetados | Sin etiquetar |
|---|---|---|
| ¿Incluyen una respuesta conocida? | Sí | No |
| ¿Requieren etiquetado manual? | Frecuentemente | No para el dato original |
| Enfoque habitual | Aprendizaje supervisado | Aprendizaje no supervisado o autosupervisado |
| Objetivo típico | Predecir una categoría o valor | Descubrir patrones o aprender representaciones |
| Ejemplo | Correo marcado como spam | Correo sin clasificar |
